# TrustScore — 3-Minute Demo Script

1. **Landing** — "This is Rahul: earns ₹28,000/month delivering, but has no
   payslip a bank recognizes." Click *Check your TrustScore*.
2. **Worker select** — Pick "Rahul Kumar (Strong worker)". Show the raw data
   profile with VERIFIED / CONSENT-BASED / SUPPORTING labels.
3. **Verification** — Submit as authorized signer → attestation accepted.
   Optionally also click "unauthorized signer" first to show the rejection
   path, then resubmit authorized.
4. **TrustScore** — Watch the score animate to 84/100. Click "Why did I get
   this score?" to open the explainability panel.
5. **Traditional vs TrustScore** — Show the side-by-side: traditional lending
   rejects Rahul; TrustScore makes him starter-credit eligible.
6. **Loan offer** — Accept the simulated loan.
7. **Repayment** — Simulate an incoming payout, then record an on-time
   repayment. Point out Repayment Performance stays visually separate from
   the 100-point score.
8. **Ladder** — Show the ladder advancing after on-time repayment.
9. *(Optional, to show the safety rails)* Switch to the "High-risk worker"
   scenario, run it to the loan screen, and show DECLINED. Then show the
   Recovery screen: trigger the day-45 10% recovery, then rehabilitate.
10. **Methodology** — Close by showing the transparent 12-signal weight
    table and the prototype disclaimer.

Use the **Hackathon Demo Mode** button to auto-play steps 2–8 in ~10 seconds
if time is short. Use **Reset Demo** between judge walkthroughs.
